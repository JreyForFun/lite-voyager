# Lite Voyager

A planned VS Code extension for browsing SQLite, CSV, JSON, and XLSX files
and querying them with SQL in an editor tab.

## Status

Repository setup and specifications are in progress. No extension code yet.
See `PROGRESS.md` and `specs/TASKS.md` for the current task.
